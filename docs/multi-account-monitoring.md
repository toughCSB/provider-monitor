# 여러 계정 모니터링

Codex와 Claude는 각각 최대 2개 계정을 표시합니다. v1.18.1부터 설정에서 공식 CLI 로그인으로 계정을 등록할 수 있습니다. 등록 계정은 `Codex 1`, `Codex 2` 또는 `Claude 1`, `Claude 2`로 표시하며, 첫 번째 등록을 해제해도 두 번째 번호는 유지합니다. 아이콘의 숫자 배지와 색상으로 구분하고, 사용량 경고 색상은 기존 의미를 유지합니다.

## 권장: 앱에서 계정 등록

1. 설정 → 계정 → **Codex 계정 추가** 또는 **Claude 계정 추가**를 선택합니다.
2. 공식 CLI가 연 브라우저에서 원하는 계정으로 로그인합니다. 다른 계정이 자동 선택되었다면 브라우저에서 계정을 바꿉니다.
3. 앱에 표시된 이메일을 확인하고 **이 계정 모니터링**을 누릅니다.
4. 두 번째 계정도 같은 순서로 추가합니다. 같은 계정을 중복 등록할 수 없습니다.

앱이 계정별 전용 폴더를 생성합니다. Codex는 `CODEX_HOME`, Claude는 `CLAUDE_CONFIG_DIR`로 공식 CLI의 인증 저장소를 분리하며, 평소 터미널의 기본 로그인과 실행 중인 세션을 전환하지 않습니다. Mac의 위치는 `~/Library/Application Support/Provider Monitor/managed-accounts`, Windows는 앱 설정 폴더의 `managed-accounts`입니다.

등록 확인이 끝나기 전에는 기존 모니터링이 유지됩니다. 해당 제공자에 등록 계정이 생기면 등록한 계정만 표시하며, 모두 등록 해제하면 기존 자동 발견 경로로 돌아갑니다. **등록 해제**는 모니터링 등록만 없애며 CLI 로그아웃이나 인증 파일 삭제를 수행하지 않습니다. 취소한 로그인 폴더도 자동 삭제하지 않습니다.

Codex 사용량은 공식 `app-server`의 `account/read`, `account/rateLimits/read`로 조회합니다. Claude는 공식 `auth status`로 계정을 확인하고 CLI의 `/usage` 출력을 읽습니다. 새 경로에서 Claude OAuth 토큰이나 키체인을 직접 읽지 않습니다. 조회 전후 계정이 다르면 수치를 표시하지 않습니다.

Mac·SV·HOME은 각각 독립적으로 로그인해야 합니다. 다른 기기의 토큰을 복사하거나 브라우저의 두 계정을 자동으로 CLI 등록 계정으로 변환하지 않습니다. 계정 사용량은 모니터링하지만, 이 등록을 평소 작업용 CLI의 계정 전환으로 간주하지 않습니다.

## Mac

- Aside의 ChatGPT 계정 전환에 두 계정이 저장되어 있으면 앱 시작 시 두 계정을 자동 연결합니다. 이 경우 CLI의 단일 계정을 중복 표시하지 않습니다.
- Aside의 현재 계정을 전환하지 않고 계정별 사용량을 조회합니다. 브라우저 저장소는 읽기만 하며, 로그인 토큰을 Provider Monitor 설정이나 파일로 복사하지 않습니다.
- 계정 설정에는 각 계정의 주소와 출처가 표시됩니다. 계정별 연결 스위치, 새로고침, 한도 선택은 독립적입니다.
- 별도 Codex·Claude 로그인 폴더를 사용하는 경우 설정 → 계정 → 고급에서 해당 폴더를 선택합니다. `~/.codex-*`, `~/.claude-*`의 유효한 추가 계정도 발견합니다. 같은 계정이나 같은 폴더를 다시 추가하면 거부합니다. 등록 계정을 쓰는 동안에는 기존 폴더를 혼합하지 않습니다.
- Claude의 추가 계정은 해당 폴더로 로그인한 Claude Code의 키체인 항목이 필요합니다. 폴더만 만들거나 기본 계정의 파일을 복사하는 것으로 두 번째 계정이 생기지 않습니다.
- 새로 추가한 Aside 계정은 Provider Monitor를 다시 시작하면 발견합니다. 이미 연결한 계정의 로그아웃·로그인 갱신은 다음 조회 때 반영됩니다. 저장소를 읽는 중 브라우저가 파일을 교체하면 그 조회를 실패 처리하고, 다른 계정의 숫자로 대체하지 않습니다.
- Aside 웹 계정에는 CLI의 활동 애니메이션을 임의로 붙이지 않습니다. 사용량과 연결 상태는 각 웹 계정의 공식 응답으로 표시합니다.

## Windows

위의 계정 등록 흐름을 사용합니다. 기존 별도 로그인 폴더는 고급 항목에서 계속 연결할 수 있습니다. Aside 웹 계정 저장소 자동 연결은 현재 Mac에서 지원합니다.

## 데이터 분리

각 계정은 별도의 표시 ID, 사용량, 연결 상태, 새로고침과 제한 대기 시간을 갖습니다. 일시적인 연결 실패는 같은 계정의 마지막 수치를 오래된 값으로 유지합니다. 로그아웃이나 계정 변경은 다른 계정의 수치를 재사용하지 않습니다. 프로바이더당 세 번째 계정은 표시하지 않습니다.

Aside 저장소 읽기는 LevelDB의 `CURRENT`와 `MANIFEST`에 기록된 현재 파일만 대상으로 하며, 삭제 기록과 순번을 반영합니다. 오래된 파일에서 로그인 정보를 추측해 복구하지 않습니다. 저장소 형식이 바뀌거나 응답의 사용자 식별자가 다르면 조회를 거부합니다.
