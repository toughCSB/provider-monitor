## 제외 조건

Grok refresh-token 직접 갱신처럼 외부 가정이 추가되는 대체 구현은 현재 공식 CLI 갱신보다 낫다는 근거 없이 넣지 않는다. codex-auth 계정 스위치, 비용 인덱서, 새 provider 전체 기능, 삭제된 CI 복원은 이번 작업에 필요하지 않다. 성능 수치는 합성 fixture와 실기기 측정을 구분한다. 커밋·push·릴리스 게시를 이번 지시에서 새로 수행하지 않는다.

## 통합과 검증

각 작업 공간은 수정 전 작업본을 복제한 별도 worktree이다. 호스트는 파일별 변경을 원본과 대조한 후 통합한다. 실제 오류를 막는 fixture, 계정 전환·취소·재시작·다운로드 실패·회복 시나리오를 검증한다. 최종 보고에는 새 실행 결과와 과거 검증을 구분하며, HOME 오프라인 등 확인하지 못한 결과를 완료로 표시하지 않는다.

## 완료 결과

Mac 1.18.4/build 30과 SV 1.18.4를 설치했다. HOME은 사용자가 후속 적용으로 지정했고 같은 설치 파일을 준비했다. Mac 전체 1,754개(3개 제외), Windows 176개(2개 제외) 검사에서 실패가 없었다. LM Studio 로그 탐색 합성 측정은 158.138ms → 0.775ms. Aside 캐시 등 입증되지 않은 변경은 적용하지 않았으며, 상세 결과와 한계는 `docs/deployments/2026-11-17-stability-1184.md`에 기록했다.
