## 보존 및 남은 사용자 로그인

기존 설치본을 백업한 뒤 앱만 업데이트했습니다. 기본 CLI의 로그인 계정을 전환하거나, 기기 간 토큰을 복사하거나, 기존 작업 세션을 재시작하지 않았습니다. 등록 해제와 취소는 CLI 인증 파일을 삭제하지 않습니다.

새 관리 계정의 브라우저 로그인은 수행하지 않았습니다. 따라서 실제 두 계정을 새 방식으로 등록한 후 사용량을 대조하는 종단 검증은 아직 남아 있습니다. 기기마다 설정의 계정 추가 버튼에서 원하는 계정으로 한 번씩 로그인하고, 표시된 이메일을 확인해야 합니다. Mac의 기존 Claude 경로는 설치 후 설정 화면에서 저장된 로그인 없음으로 표시되었으므로 새 계정 등록 시 로그인이 필요합니다.

이번 기능 소스는 커밋·푸시하지 않았습니다. 이전 미커밋 변경도 보존했습니다.
