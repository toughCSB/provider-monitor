# HOME 계정·설정의 SV·Mac 적용

사용자가 HOME의 로그인 정보와 설정을 SV·Mac에도 적용하도록 명시적으로 요청한 뒤 수행한 1회 복사입니다. 지속적인 인증 자동 동기화는 설정하지 않았습니다.

## 확인 결과

HOME에 등록된 관리 계정은 Codex 두 개였습니다. 실제 계정별 인증과 사용량 조회 결과를 대조했습니다.

| HOME 계정 | SV | Mac | 확인 시 표시 잔여량 |
|---|---|---|---|
| toughCSB, 슬롯 1 | toughCSB | Codex 1 | 세 기기 모두 100% |
| HolyGlass, 슬롯 2 | HolyGlass | Codex 2 | 세 기기 모두 83% |

SV는 등록 신원과 조회 신원이 일치하고 두 계정 모두 `ok`임을 확인했습니다. Mac은 실제 설정 창에서 각 계정 이메일과 등록 상태, 노치의 두 수치를 확인했습니다. HOME의 앱과 로그인은 그대로 유지했습니다.

## 적용 범위

- Codex 공식 CLI가 저장한 각 계정의 `auth.json`만 SSH를 통해 앱 전용 저장소로 복사했습니다. 일반 `~/.codex` 로그인이나 기존 작업 세션은 변경하지 않았습니다.
- SV는 계정 별명, 표시 순서, 한도 기준, 오른쪽 배치, 크기 80%, 남은 비율, 주간 링, 언어, 최상단 표시 및 트레이 설정을 반영했습니다. 기기 고유 포트와 모니터 식별자는 유지했습니다.
- Mac은 계정 ID를 UUID 형식으로 변환하고 계정 순서, 한도 기준, 크기 80%, 남은 비율, 오른쪽 배치, 상대 위치, 언어, 주간 링과 최상단 표시를 반영했습니다. Windows 트레이에 대응하도록 메뉴 막대 아이콘을 켰습니다.
- Mac에서 인증되지 않은 다른 제공자를 새로 연결하지 않았습니다. 기존 연결의 순서를 HOME 기준으로 정렬했습니다. HOME에 별도로 등록한 Claude 관리 계정은 없었으므로 Claude 인증은 이번 복사에 포함하지 않았습니다.
- Mac 버전은 사용자 지정 계정 별명과 Windows 트레이의 막대 그림을 지원하지 않습니다. 각각 Codex 1·2와 Mac 메뉴 막대 아이콘으로 대응했습니다. 화면별 실제 위치는 운영체제의 크기·배치 차이에 따라 달라질 수 있습니다.

## 보존과 정리

기존 대상 설정을 백업했고 이전 계정 폴더는 삭제하지 않았습니다. 새 Mac 인증 파일은 0600, 계정 폴더는 0700으로 저장했습니다. Windows 전송·대상 계정 폴더는 해당 사용자와 SYSTEM만 접근하도록 설정했습니다. HOME·SV·Mac의 임시 전송 인증 파일은 모두 삭제했습니다. 인증 값은 보고서나 명령 출력에 포함하지 않았습니다.

SV 설정 백업: `%LOCALAPPDATA%\ProviderMonitor-backups\before-home-sync-20261116-001205`

Mac 설정 백업: `~/Library/Application Support/Provider Monitor/backups/before-home-sync-16AF3AB2-DC46-41EF-A3D3-8A8D8FBDF60A/preferences.plist`

앱 코드와 버전은 변경하지 않았으며 세 기기 모두 1.18.1을 유지합니다.
