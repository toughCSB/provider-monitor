# 1.18.3 세션 복구·설정 화면 수정

## 확인한 원인과 수정

| 증상 | 확인한 원인 | 적용한 수정 |
|---|---|---|
| Codex에 큰 분 단위 숫자 표시 | 등록 계정 경로가 주간 한도 기간을 `10080 min`으로 표시. 실제 재설정 시각과는 별개 | 기존 Codex와 같은 한도 이름 사용. 주간·월간·일 단위 표시와 실제 재설정 시각 보존 검증 |
| Windows 드롭다운 글자가 보이지 않음 | 네이티브 선택 목록의 배경색과 글자색 조합 | dark color-scheme, 불투명 배경, 선택·비활성 항목 색 지정 |
| 설정 상단의 `No login in progress` 경고 | 로그인 중이 아닌 계정을 2초마다 조회하며 정상적인 빈 상태를 오류로 표시 | 초기 상태 복원 후 진행 중인 로그인만 조회. 취소 중 응답 경합 처리. 실제 예외는 유지 |
| AGY 사용량이 오래되거나 연결 실패처럼 보임 | SV 실제 CLI 출력의 `2026-11-21 17:24 KST`를 RFC3339 전용 파서가 거부 | KST·UTC·GMT 해석. 재설정 시각만 없으면 유효한 사용량은 유지. 잘못된 퍼센트는 계속 거부 |
| Grok 만료 후 재로그인 요구 | `grok agent --reauth stdio`에 즉시 EOF를 주면 종료 코드 0이어도 인증 갱신 전에 종료 | 입력 파이프를 열어 두되 아무 요청도 보내지 않음. 제한 시간 후 자체 프로세스를 회수하고, 실제 만료 시각이 늘었는지 확인 |
| 일시적인 장애 후 자동 갱신이 영구 중단 | 같은 토큰에 3번 실패하면 앱 재시작 전까지 재시도하지 않음 | 제한된 재시도 묶음이 실패해도 1시간 후 다시 시도. CLI가 나중에 설치된 경우 다시 탐색 |
| 등록한 Claude의 조회 실패가 재로그인으로 표시 | 일반 CLI 실패 메시지에 sign-in 문구가 포함되어 인증 오류로 분류 | 조회 전후 공식 인증 상태와 계정 일치 확인. 같은 계정의 일시 실패는 이전 정상값 유지, 실제 로그아웃·계정 변경은 분리 |

Windows Claude 갱신은 npm `.cmd` 실행 파일도 지원하며 상속된 인증 환경 변수를 제거하고 해당 프로필만 지정한다. 갱신용 자식 프로세스는 제한 시간 후 자신이 시작한 프로세스 트리만 종료한다. 기존 사용자 CLI 세션과 인증 파일을 삭제하거나 다른 기기로 복사하지 않았다.

## 실제 동작 증거

- SV Grok: 동일한 공식 명령에 즉시 EOF를 주면 만료 시각이 변하지 않았고, 입력을 열어 둔 경우 재로그인 없이 만료 시각이 연장됐다. 종료 코드만으로 성공을 판단하지 않았다.
- SV AGY: 공식 CLI의 실제 KST 출력으로 4개 한도를 읽었다. 설치 후 앱의 `antigravity.json`도 `ok`, 4개 한도, 새 측정 시각을 기록했다.
- SV 설치 후 Grok과 Codex 두 등록 계정은 `ok`. Codex 두 계정 모두 `Weekly limit`으로 저장됐다.
- SV Claude는 설치 직후 서버 요청 제한으로 `stale`과 backoff를 기록하고 마지막 정상값을 보존했다. 이후 자동 재시도로 새 측정 시각과 `ok` 상태로 회복한 것을 확인했다. 이 과정에 재로그인은 없었다.
- Mac 설치 후 저장된 Codex 두 계정의 이름은 `주간 한도`. AGY 4개, Grok 1개, 등록 Claude 3개의 사용량 항목이 보존돼 있었다. 기본 키체인 조회는 status 0이었다.

## 검증

- Windows 네이티브 Rust 테스트: **165 통과, 0 실패, 2 제외**.
- Windows UI 스크립트 문법, 등록 계정 렌더러, 실제 로그인 폴링 함수 테스트 통과. 정상 대기·재개·취소 경합·진짜 오류 표시를 검사했다.
- Mac 인증·갱신 관련 최종 테스트: **50 통과, 0 실패**.
- Mac Grok EOF 회귀 테스트는 수정 전 실제 실패, 수정 후 통과를 확인했다.
- Mac 전체 테스트 실행: **1,724개, 7개 제외, 애니메이션 관련 assertion 실패 7건**. 화면이 잠긴 상태였고 `EdgeArrivalTests` / `EdgeCrossfadeTests`에서 실패했다. 잠금이 유일한 원인인지는 확인하지 못했으므로 전체 통과로 보고하지 않는다.
- Mac universal Release 및 Windows NSIS 빌드 성공. `git diff --check` 통과.
- Mac 화면 잠금으로 실제 UI 확인이 불가능했다. Windows 네이티브 드롭다운의 최종 화면도 시각적으로 확인하지 못했다.
